Rebuilding a WebXR learning pathway

Student-facing WebXR labs and setup materials that help beginning creative technology students move from a 360° image to an interactive virtual environment.

ATLS 2100: ImageA-FrameHTML / CSS / JavaScriptGitHub
The context

As a Learning Assistant and later Head LA for ATLS 2100: Image at CU Boulder, I supported project-based labs and helped update the course’s virtual reality workflow as the previous Glitch platform became unavailable. Students needed a pathway into code editing, previewing, and publishing that did not assume prior programming experience.

The design question

How might we lower the friction of the technical setup so students can focus more of their energy on creative exploration?

What I designed and contributed

  • Helped migrate the course’s WebXR assignments from Glitch to a GitHub-based workflow.
  • Contributed instructions for GitHub Codespaces, live preview, GitHub Pages, and submission steps.
  • Supported the Image + Space assignment sequence involving equirectangular imagery, A-Frame environments, and 3D objects.
  • Led lab-style instruction and troubleshooting, helping students move from a clear starting point toward open-ended projects.

Good technical instruction should make the first steps understandable without removing room for experimentation. I aim for a low floor and high ceiling: students can get something working, then extend it through their own creative choices.

Where this work stands

A collaborative course-development contribution. Individual assignment ownership and examples will be labeled precisely when original materials are added.

Artifacts to add
